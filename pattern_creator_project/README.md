# Pattern Creator

Публичный веб-редактор узоров с сеткой от 12×12 до 64×64, рисованием мышью и пальцем и отправкой PNG на почту.

## Запуск на компьютере

Нужен Node.js 20 или новее.

```bash
npm install
```

Скопируй `.env.example` в `.env` и заполни `RESEND_API_KEY` и `EMAIL_FROM`.

```bash
npm start
```

Открой http://localhost:3000.

## Настройка отправки писем

Письма отправляются через Resend API. В Resend создай API key и подтверди домен отправителя. Укажи адрес отправителя с этого домена в `EMAIL_FROM`. Получатель по умолчанию: `sodimmlit@gmail.com`.

Важно: Resend не позволит отправлять письма с произвольного неподтверждённого адреса. Для реальной отправки нужен подтверждённый домен отправителя и API key. Ключ хранится только в переменных окружения сервера, не в браузере.

## Публикация на Render

1. Загрузи содержимое проекта в новый GitHub-репозиторий.
2. На Render создай **New → Web Service** и подключи репозиторий.
3. Build Command: `npm install`.
4. Start Command: `npm start`.
5. В Environment добавь `RESEND_API_KEY`, `EMAIL_FROM`, при желании `RECIPIENT_EMAIL`.
6. Нажми Deploy. Render выдаст публичную ссылку вида `https://имя-сервиса.onrender.com`.

Для работы отправки сайт должен быть опубликован как Node Web Service, а не как статический сайт.

## Что умеет редактор

- Квадратная сетка 12, 14, 16 … 64.
- Рисование протягиванием мыши или пальца.
- Чёрный выступ, красная впадина, ластик.
- Очистка всего поля.
- Ник сохраняется в браузере посетителя.
- Каждая отправка создаёт отдельное письмо с PNG-вложением.
- Ограничение частоты запросов и проверка входных данных на сервере.
